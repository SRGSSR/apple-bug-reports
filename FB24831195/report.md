# NavigationLinkPickerStyle

## Description

Using `.navigationLink` as a picker style doesn't seem to work.

### Steps to Reproduce

1. Launch the app.
2. Try to choose a flavor.

### Expected Result

The app should display a list of available flavors, allowing the user to select one.

### Actual Result

The app does not display the list of flavors, and no flavor can be selected.

## Configuration

- OS Version: tvOS 27.0
- Device: Apple TV 4K (A2169)
- Xcode Version: 27.0 (27A266a)
